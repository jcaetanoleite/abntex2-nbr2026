# Fluxo de colaboração pelo site do GitHub

Este repositório foi pensado para poder ser usado e desenvolvido inteiramente
pela interface web do GitHub.

## Usar no Overleaf

1. Abra a pasta `latex/` no GitHub.
2. Abra cada um dos três arquivos.
3. Clique em **Download raw file**.
4. Faça upload dos três arquivos no projeto do Overleaf, na mesma pasta do
   arquivo `.tex`.
5. Use o preâmbulo mostrado no `README.md`.

## Propor uma alteração neste repositório

1. Abra o arquivo no GitHub.
2. Clique no ícone de edição.
3. O GitHub criará uma branch automaticamente se necessário.
4. Salve a alteração e abra um Pull Request.

## Contribuir com os projetos oficiais

As mudanças de estrutura/documento pertencem ao `abntex/abntex2`; as mudanças
de citações e referências pertencem ao `abntex/biblatex-abnt`. Por isso, uma
contribuição upstream deve ser dividida em dois Pull Requests.

Os diffs correspondentes ficam na pasta `patches/`. Antes de abrir PRs oficiais,
a matriz `NORMATIVE-MATRIX.md` deve estar suficientemente auditada, sobretudo
nos casos ainda pendentes da NBR 6023:2025.
